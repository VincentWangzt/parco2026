## 1 矩阵–向量乘法

矩阵–向量乘法（Matrix–Vector Multiplication，常缩写为 GEMV）是稠密线性代数中最基本的运算之一，广泛出现在迭代求解器（如 Krylov 子空间法、共轭梯度法）、图分析（PageRank）、深度学习推理等场景中。

给定一个 $N \times N$ 的矩阵 $A$ 和一个长度为 $N$ 的向量 $x$，矩阵–向量乘法计算

$$y = A \cdot x, \qquad y_i = \sum_{j=0}^{N-1} A_{ij}\, x_j, \quad i = 0, 1, \ldots, N-1.$$

### 1.1 算法流程

串行算法的时间复杂度为 $O(N^2)$，串行代码如下：

```cpp
for (long i = 0; i < N; ++i) {
    long long s = 0;
    for (long j = 0; j < N; ++j)
        s += A[i][j] * x[j];
    y[i] = s;
}
```

**确定性数据初始化**　为了便于自动化批改与跨机器复现，本作业要求矩阵 $A$ 与向量 $x$ 均由**确定性公式**生成，**不允许使用 `rand()` 等随机数**：

$$A_{ij} = (i \cdot 7 + j \cdot 13) \bmod 1000, \qquad x_j = (j \cdot 3 + 1) \bmod 100.$$

由此得到的 $y$ 是确定的 64 位整数序列，助教提供的验证脚本 `verify.py` 可对 $y$ 做**逐元素精确比对**，不存在浮点公差问题。

### 1.2 并行化策略

注意到不同的 $y_i$ 之间是**完全独立**的，因此矩阵的行天然适合作为并行任务的最小单位。下面列举三种典型的数据划分方式。

**1D 行块划分（推荐）**　将 $A$ 的 $N$ 行按块划分给 $p$ 个进程，进程 $r$ 持有第 $start_r$ 到 $end_r - 1$ 行（共 $local\_rows_r$ 行），每个进程额外保留一份完整的 $x$。每个进程独立计算 $local\_y_r$，最后用 `MPI_Gather` 或 `MPI_Gatherv` 汇集到 0 号进程。通信轮数仅为 1，实现最简单，是本作业推荐的方案。

**1D 列块划分**　将 $A$ 按列划分，$x$ 同样按列划分。每个进程计算部分和后用 `MPI_Reduce`（或 `MPI_Allreduce`）求和。本方案通信量较大（要 reduce 一个长度为 $N$ 的向量），仅作了解。

**2D 块划分（拓展）**　将 $p = \sqrt{p} \times \sqrt{p}$ 个进程排成方阵，$A$ 切成二维块（Fox / SUMMA 算法）。通信量最优但实现较复杂，作为有兴趣同学的拓展方向。

**数据划分不整除的处理**　若 $N$ 不被进程数 $p$ 整除，则必须使用 `MPI_Gatherv`，并显式构造 `recvcounts[]` 与 `displs[]` 数组，否则会出现"接收长度对不齐"的运行时错误或结果错位。本作业的算例 M（见下表）**特意设计为不被 16 整除**，就是为了考察这一情形。
