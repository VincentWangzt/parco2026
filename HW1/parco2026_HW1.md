## 1 直方图统计算法

直方图统计（Histogram Computation）是一种将连续数据离散化统计的基本方法，广泛应用于图像处理、数据分析和机器学习等领域。给定 $N$ 个浮点数 $x_0, x_1, \ldots, x_{N-1}$，以及值域范围 $[min, max]$ 和区间数 $M$，直方图统计的目标是统计每个区间（bin）中数据点的个数。

### 1.1 算法流程

将值域 $[min, max]$ 均匀划分为 $M$ 个宽度相等的区间，第 $k$ 个区间为 $[min + k \cdot w, \ min + (k+1) \cdot w)$，其中 $w = (max - min)/M$。

对于每个数据点 $x_i$，计算其所属区间编号并累加计数：

1. 初始化：$hist[k] = 0$，$k = 0, 1, \ldots, M-1$。

2. 对于每个数据点 $x_i$（$i$ 从 0 到 $N-1$）：

   (a) 计算所属区间编号：$bin = \left\lfloor \dfrac{x_i - min}{w} \right\rfloor$，

   (b) 对该区间计数加一：$hist[bin] += 1$。

串行算法的时间复杂度为 $O(N)$，串行代码如下：

```c
double bin_width = (max_val - min_val) / M;
for (int i = 0; i < N; ++i) {
    int bin = (int)((data[i] - min_val) / bin_width);
    hist[bin]++;
}
```

### 1.2 并行化的挑战

**数据竞争（Race Condition）** 当多个线程同时执行 `hist[bin]++` 时，由于该操作由"读—加—写"三步组成，多线程并发执行会导致计数丢失。例如，线程 A 和线程 B 同时读取 `hist[k] = 5`，各自加 1 后写回 6，而正确结果应为 7。

解决数据竞争的常见策略包括：

- **原子操作**：使用 `#pragma omp atomic` 保证每次加法的原子性，实现简单但在高竞争时性能较差。

- **线程私有数组 + 归约**：每个线程维护一份私有直方图，并行阶段结束后串行归约，无竞争但内存占用较大。

- **临界区**：使用 `#pragma omp critical`，开销最大，不推荐。

**伪共享（False Sharing）** CPU 缓存以缓存行（Cache Line，通常 64 字节）为最小单位读写。若多个线程频繁写入同一缓存行的不同位置（如相邻的 bin），即使它们操作的是不同变量，也会导致缓存行在各核之间反复失效和同步，造成显著的性能下降。这一现象称为**伪共享**。

对于线程私有数组方案，若直接使用二维数组 `local_hist[T][M]`，则相邻线程的数组行在内存中紧邻，极易发生伪共享。解决方法是在每行末尾添加填充（padding），使不同线程的数据落在不同缓存行上。
