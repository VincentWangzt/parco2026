# 并行计算 II · 作业 3：CUDA 并行前缀和

## 1. 题目

实现一维数组的并行前缀和（inclusive scan）

\[
  y_i = \sum_{j=0}^{i} x_j,\qquad i=0,1,\ldots,N-1.
\]

其中 \(x\) 和 \(y\) 均为长度为 \(N\) 的整数数组。

### 1.1 串行算法

```
y[0] = x[0]
for i = 1 to N-1 do
    y[i] = y[i-1] + x[i]
end for
```

### 1.2 数据生成（必须严格使用以下公式）

为了便于自动化验证，本作业不使用随机数，而是用确定性公式生成输入：

```
x[i] = (i * 17 + 13) % 1000
```

学生程序应在 CPU 端或 GPU 端用该公式生成输入数组，不需要提交输入数据文件。

## 2. 作业要求

- 阅读 `serial.cpp`，理解串行前缀和的计算与输出格式。
- 完成 `parallel.cu`：
  1. 分配主机端和设备端数组；
  2. 生成输入数组 `x`；
  3. 设计并调用 CUDA kernel 完成前缀和；
  4. 将结果拷回主机端；
  5. 将结果写入 `scan_N<N>.txt`。
- 必须使用 CUDA C/C++，不允许调用 Thrust、CUB、cuBLAS 等现成并行前缀和库。
- 建议实现方式：
  - 每个 block 内用 shared memory 做局部 scan；
  - 对每个 block 的块和再做一次 scan；
  - 将块偏移量加回各 block 的局部结果。
- 完成下表中的三个算例：

  | 算例 | `N` | 主要考察目的 |
  |---|---:|---|
  | S | 32 | 正确性 / 截图 |
  | M | 1000003 | 非 2 的幂规模 / 自动验证 |
  | L | 8388608 | 性能与加速比测量 |

- 使用一张 GPU 即可完成所有实验。
- 提交：
  - 完成的 `parallel.cu`；
  - `N = 32` 情况下的运行截图；
  - 用 `verify.py` 验证 `N = 1000003` 得到 `PASS` 的截图；
  - 算例 L 的串行时间、CUDA 时间和加速比；
  - 详细报告：算法思路、block 大小选择、运行时间观察。
- 输出格式：程序将最终的 `y` 写入文件 `scan_N<N>.txt`，每行一个整数，共 `N` 行。该文件是 `verify.py` 的输入。

## 3. 编译与运行

```bash
make
./serial 32
./parallel 32
sbatch run.slurm
```

## 4. 自动验证

`verify.py` 会用同样的公式重建参考答案，对结果文件做逐元素比对：

```bash
python3 verify.py scan_N1000003.txt
# PASS: all 1000003 elements match the reference prefix sum.
```

如有任何不一致，会打印前 10 个差异的下标、实际值与期望值。
退出码：`0` 表示 PASS，`1` 表示 FAIL，`2` 表示文件读取错误。
